# 安卓「红果短视频」接入

功能入口：葫芦娃 → 功能 → 红果短视频。

首页提供“推荐 / 排行榜 / 搜索”三个页签：

- 推荐：短剧频道精选，首屏不足时合并公开真人剧和漫剧频道。
- 排行榜：全部、真人剧、漫剧、AI 剧、系列剧和演员榜，可切换子榜并分页加载。
- 搜索：剧名搜索、加载更多、剧集详情、分集选择、清晰度切换、全屏、自动连播和本地断点续播。

需要解锁的分集会显示锁定状态，不发起播放请求。

## 默认连接

默认签名服务地址为 `http://192.168.3.77:8901`（飞牛 NAS），可在入口右上角「连接设置」修改。
安卓不需要导入设备资料或填写设备 ID。

Debian 上的默认实现已从 redroid + Frida 切换为
[独立 Go 签名服务](portable-signer/README.md)。它使用 openhongguo v0.2.0 的公开 SDK
注册匿名设备，不需要 Android、ADB 或 Frida，冷启动约 1 秒。`/sign`、`/info` 和
`/recover` 的接口保持兼容；设备档案保存在 Docker 卷中，重启服务不会更换身份。

葫芦娃后端每次请求红果元数据前，先从同一签名服务的 `/info` 读取当前匿名设备的
`deviceProfile`，使用其中的 `device_id / iid / cdid` 等参数构造完整 URL，再调用 `/sign`。
设备更换后，下次请求会自动使用新的设备信息。
旧版手动导入配置和 `hongguo-device-profile.json` 文件不再作为请求身份来源。

### 签名服务的设备信息

普通 GET 的 `/sign` 请求保持兼容。播放取址按 openhongguo PR #7 改为
`POST /novel/player/video_model/v1/`，`video_platform=3`；葫芦娃将同一份原始 JSON
通过 `/sign` 的可选 `body` 字段交给 8901 服务，实际请求不再重新序列化。
播放专用签名使用完整 Argus/Ladon 和 `X-SS-STUB`，不携带 `X-Medusa`。
安卓继续使用原播放 API，接收明文或 CENC 加密流，复用现有本机解密逻辑。

`/info` 提供 `supportsRecovery: true`、当前设备信息
以及 `recoveryMode`。独立服务返回 `recoveryMode: "rotate-device"`：

```json
{
  "deviceProfile": {
    "params": {
      "device_id": "当前匿名设备的值",
      "iid": "当前匿名设备的值",
      "cdid": "当前匿名设备的值"
    },
    "user_agent": "当前匿名设备对应的 User-Agent"
  }
}
```

实际 `params` 还包含应用版本、机型、系统和渠道等公共参数。独立服务只从匿名档案中
提取白名单字段，不返回 Cookie、设备令牌或完整原始 URL。

[enable_signer_device_info.py](enable_signer_device_info.py) 只用于给旧 redroid
`sign_server.py` 补设备信息和恢复能力，不属于当前默认架构。回退时才需要：

```bash
python3 enable_signer_device_info.py /path/to/sign_server.py
# 随后重启签名进程；Docker 镜像升级或重建时，也需使用已更新的源文件。
```

自检脚本也默认使用签名服务的当前设备：

```bash
python3 hg_video_check.py --server http://192.168.3.77:8901 --mode chain
```

显式指定 `--device-from-container`、`--device-profile` 和导出 JSON 的参数仍保留供排查使用。

## 播放请求被拒绝时的恢复

`110 / ILLEGAL_ACCESS` 表示红果拒绝本次访问，不能单凭此码判断设备 ID 失效或被封禁。
此前的 redroid 服务在设备身份不变时也可能出现“搜索正常、播放被拒绝”，后台重启 App
才能恢复。该方案现已停用，Debian 默认改用独立 SDK 注册匿名设备。

葫芦娃后端在播放模型返回 110 时调用一次 `POST /recover`。独立签名服务会：

1. 在冷却窗口外注册一台新的匿名设备，旧档案保留时间戳备份。
2. 立即把新设备载入内存，后续播放请求按新设备重新生成专用签名。
3. 葫芦娃重新读取 `/info`，用新设备构造 URL 并重试播放模型一次。
4. 仍被拒绝时返回明确错误，不循环换设备。

30 秒内的并发恢复请求会合并，只更换一次设备。正常播放不受影响，也没有额外上游预检。
`/info` 的 `recoveries` 是当前进程累计更换次数，`recoveryMode` 为 `rotate-device`。

### 已验证的恢复路径

2026-11-05 在 Debian 13 上完成以下实测：

| 步骤 | 结果 |
|---|---|
| 全新卷启动独立服务 | 约 1.0 秒完成 SDK 自注册，无 Android/Frida |
| 搜索、90 集详情、播放模型、CDN Range | 全部通过 |
| `POST /recover` | 设备 ID 确实变化，返回 HTTP 200 |
| 换设备后用原样本重新播放 | 搜索、详情、播放模型、CDN Range 全部通过 |
| 冷却期内再次恢复 | 返回 `rotated: false`，没有重复注册 |

这套方案去掉了 App 状态失效和冷启动等待，但不能证明匿名播放配额永久充足；
遇到上游设备策略变化时仍需重新验证 SDK 与接口版本。

## 数据与播放流程

```text
安卓搜索 / 选择分集
  → 葫芦娃后端从签名服务 /info 读取当前设备
  → 葫芦娃后端构造完整 URL
  → /sign 返回签名头
  → 红果搜索、详情及 video_model 接口
  → 安卓拿到各清晰度 URL、spade_a 和加密描述
  → 安卓直接对 CDN 做 Range 请求
  → Kotlin 解包内容密钥、解析 MP4、逐样本 AES-CTR 解密
  → Media3 / Android 解码播放
```

后端不下载或解密视频，不把葫芦娃登录令牌转发给 CDN。
安卓仅把当前请求的数据段解密给播放器；索引在同一播放实例的拖动请求之间复用。

### 安卓实现

- `data/HongguoRepository.kt`：元数据接口和数据模型。
- `HongguoViewModel.kt`：搜索、选集、清晰度、请求取消和连播状态。
- `data/HongguoHistoryStore.kt`：按服务器和账号隔离的分集进度，不保存播放 URL 或密钥。
- `hongguo/HongguoKey.kt`：从 `spade_a` 解包 AES-128 内容密钥，参考 Apache-2.0 的 openhongguo。
- `hongguo/CencMp4.kt`：普通 MP4 的轨道索引、8/16 字节 IV、局部加密、随机位置 CTR 处理。
- `hongguo/HongguoDataSource.kt`：限量下载元数据，直接读取 CDN 媒体；同长度修补加密标记，保持 chunk 偏移。
- `ui/HongguoScreen.kt`、`ui/HongguoPlayer.kt`：原生搜索详情页及 Media3 播放器。

当前支持普通 MP4 的内置 `senc` 索引和 `cenc` AES-CTR。暂不支持分片 MP4、外置辅助加密索引、
密钥轮换和其他加密方式；遇到这些格式会明确报错。ByteVC2 不进入可选清晰度列表，HEVC/H.264
等编码仍取决于手机解码能力。

### 后端接口

以下接口统一要求葫芦娃登录认证，使用既有 `ApiResult` 信封。

| 接口 | 说明 |
|---|---|
| `GET /api/hongguo/settings` | 连接状态和当前设备型号 |
| `POST /api/hongguo/settings` | 保存 `signUrl`，设备资料自动获取 |
| `POST /api/hongguo/settings/sync` | 刷新签名服务当前的设备状态 |
| `GET /api/hongguo/discover` | 推荐页短剧，去重后返回封面、简介和集数 |
| `GET /api/hongguo/ranking?content=&board=&cursor=` | 排行榜目录、榜单条目和下一页游标 |
| `GET /api/hongguo/search?query=剧名&offset=0` | 去重后的剧集结果和下一页偏移 |
| `GET /api/hongguo/series/{id}` | 剧集详情及分集目录 |
| `GET /api/hongguo/episodes/{id}/playback` | 当前有效的播放地址和每条流的加密信息 |

推荐使用 `bookmall/tab/v` 的 `tab_type=-1 / 16`，不足时补充真人剧 `39` 和漫剧 `36`。
排行榜使用 `bookmall/cell/change/v1` 的 `tab_type=26`；后端游标携带分类、子榜、偏移、会话和
已展示作品，翻页不会重复。演员榜按用户 ID 返回，演员行显示头像、人气和作品数。

原生入口由 `AndroidSessionService` 仅向安卓下发，已有数据库升级后自动出现。
若需修改名称或隐藏入口，可在 `chat.android.sessions` 中显式增加 `kind: "hongguo"` 的条目；
配置 `enabled: false` 会覆盖默认入口。聊天数据结构和归档网页端保持兼容。
