# 安卓红果功能已移除

葫芦娃安卓 App 已移除红果短剧入口、搜索推荐、排行榜、收藏、播放及离线缓存。
后端不再提供 `/api/hongguo/**` 接口。
历史会话配置与客户端快照中的相关入口会自动忽略。

红果TV App 打包入口、后端构建与公开更新接口，以及 Debian 专用构建服务继续保留。

红果算法 Docker 服务独立保留，不依赖葫芦娃后端：

- [独立 Go 签名服务](portable-signer/README.md)：保留代码、镜像构建与 Compose 配置。
- [原 Android 签名服务](../hongguo-sign/README.md)：保留部署文件与数据卷配置。
- 仓库根目录的 `hongguo-docker.zip` 原始服务包继续保留。
