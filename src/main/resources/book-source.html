导入到「阅读」App 的步骤
  1. 点击上方按钮，浏览器会下载 .json 文件。
  2. 把文件传到手机（微信传输助手、文件管理器均可）。
  3. 打开阅读 App → 我的 → 书源管理 → 右上角菜单 → 本地导入。
  4. 选择该 JSON 文件，导入后确认书源为「启用」状态。
  5. 在阅读里搜索书名即可，搜到的书也会同步到葫芦娃书架。

这个 JSON 内嵌了书源访问令牌，等同于密码，请不要公开分享。 如果怀疑泄露，可在葫芦娃管理端吊销全部书源令牌。
