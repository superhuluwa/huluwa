# 葫芦娃 · 我的与服务状态设计

推荐把「我的」升级为：账号 → 服务器资源 → FRP / Docker 摘要 → 连接与账户。延续当前松柏绿视觉和「功能 / 系统 / AI / 下载 / 我的」导航。

本目录为独立设计交付，使用示例数据，不连接业务服务器，不修改 Android、网页和后端业务源码。

## 文件

`index.html` / `styles.css` / `app.js` 为静态交互原型；`assets/` 为本地品牌图标和字体。所有时间、账号、地址、容器、版本与指标均为演示内容。原型操作仅展示界面效果，刷新页面恢复初始数据。

设计图展示四个主页面，更多内容可在每台手机内滚动查看。状态控件在页面顶部，可切换日常运行、局部异常、服务器断连、尚无资源与首次加载。

交互原型使用紧凑的画板比例；原生落地时需要沿用 App 的字体缩放、48dp 触控区域与真实系统安全区。实现说明见调研文档。
