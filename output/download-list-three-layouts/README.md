# 葫芦娃 App 下载页：三种列表布局

本目录是独立的交互设计原型，沿用 Android 现有主题与任务来源。直接打开 `index.html` 即可预览，所有演示操作只修改页面内存中的示例数据。

| 方案 | 布局 | 适合场景 |
| --- | --- | --- |
| 01 极简清单（推荐） | 状态筛选 + 连续分隔线列表；每行展示来源、剧名、集数、进度、百分比、容量、速度或异常状态 | 日常浏览，优先列表效率 |
| 02 状态分组 | 紧凑摘要 + 下载中、需要处理、等待与暂停、已完成分组；组内连续列表，可折叠 | 任务较多，优先处理异常与进行中的任务 |
| 03 来源分栏 | 左侧来源栏 + 右侧任务列表；支持全部、剧集、磁力、迅雷切换 | 同时使用多个下载器 |

## 配色与依据

配色读取自 `android/app/src/main/java/com/huluwa/android/ui/Theme.kt`：

- 松柏绿：`#206C54`
- 深松柏绿：`#194F3E`
- 雾白底色：`#F6F8F5`
- 深色文字：`#243D32`
- 次级文字：`#63746A`
- 分隔线：`#E3EAE0`
- 剧集、磁力、迅雷来源色：`#206C54`、`#4E78A7`、`#8260A1`
- 异常提示：`#B44452`

任务字段与能力参考 `DownloadsScreen.kt` 和 `data/Models.kt`。底部导航沿用当前“功能 / 系统 / 下载 / 我的”四个入口。三版使用相同的八项示例任务，便于公平比较。

## 可体验的交互

- 搜索名称、集数或下载来源；无结果时显示空状态。
- 第一版切换全部、下载中、已完成、异常；第一、三版支持默认与名称排序。
- 第二版展开与折叠状态分组。
- 第三版按下载来源切换任务，计数与速度随筛选更新。
- 点击任务标题查看详情、完整保存路径；可复制路径。
- 更多菜单保留离线剧集的取消、重试、查看日志，以及通用详情入口。
- 设置弹层展示各来源设置与清空记录入口。
- 清空、取消、重试只改变当前方案的示例数据；页面底部可重置全部演示。

## 文件

- `index.html`：三方案比较页面。
- `styles.css`：复用主题配色的布局、窄屏适配与弹层样式。
- `app.js`：示例任务与交互逻辑，无第三方依赖、无后端请求。
- `preview-three.png`：三种布局并排预览。
- `preview-list.png`、`preview-groups.png`、`preview-sources.png`：各方案单独预览。
