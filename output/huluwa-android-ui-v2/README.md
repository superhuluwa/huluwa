# 葫芦娃 Android UI · 三套落地方案

这是第二版重新设计，不再沿用松白、晴蓝、暖砂，也不再采用展示海报式布局。三套方案都按真实 Android App 的页面约束制作：顶部应用栏、可在安全区内滚动的内容、五个一级入口、底部导航、列表与任务状态、会话输入框和原生弹层。

## 三套方案

| 方案 | 视觉定位 | 组件与信息组织 |
| --- | --- | --- |
| 澄海 | 清爽、可信赖、接近 Material 3 | 白底蓝主色，圆角卡片，清晰主卡片；标准五标签导航，适合最广用户群 |
| 玄铁 | 深色、高效率、状态优先 | 深色层级和青绿色状态色，紧凑任务与系统管理；高频操作路径更短 |
| 蜜桃 | 轻生活、内容感、柔和圆润 | 暖白和桃粉，非对称圆角，内容入口更突出；仍保留完整工具结构 |

所有方案都覆盖：功能首页、系统管理、下载、订阅、我的、会话详情、空状态和操作弹层。页面数据仅为本地示例，不连接业务服务器。

## 打开方式

直接打开 `index.html`，或在同目录启动任意静态服务器。预览页顶部可以：

- 三套并排查看；
- 单套切换查看；
- 同步切换页面；
- 切换空状态。

在 600px 以下宽度，预览自动进入单机型模式，去掉桌面手机框，以屏幕宽度展示真实 App 布局。

## 交互范围

- 五标签底部导航；
- 功能页服务入口与弹层；
- 系统页管理入口；
- 下载筛选、任务详情与新建任务入口；
- 订阅管理与检查弹层；
- 我的页账户、通知、主题与退出入口；
- 会话输入框与消息展示；
- 空状态切换。

## 源码对应

- 一级入口：`android/app/src/main/java/com/huluwa/android/ui/HuluwaRoot.kt`
- 功能与系统：`SessionsScreen.kt`
- 下载：`DownloadsScreen.kt`
- 订阅：`SubscriptionsScreen.kt`
- 我的：`MineScreen.kt`
- 会话：`ChatScreen.kt`
- 主题：`Theme.kt`、`Components.kt`

原型未修改上述 Android 源码，也未添加接口或业务功能。
