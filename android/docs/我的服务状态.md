# 我的 · 服务器与服务状态

「我的」现在展示账号与消息同步、服务器 CPU / 内存摘要、FRP 隧道摘要、Docker 容器摘要，以及原有连接与账户入口。卡片进入服务器状态详情或现有 FRP / Docker 管理会话，返回时保留主标签和页面滚动位置。

## 数据接入

| 内容 | 接口 | 行为 |
| --- | --- | --- |
| 服务器 CPU、内存、平均负载 | `GET /api/dashboard/server` | 读取服务端缓存快照；缺失数值保持未知 |
| FRP 进程与隧道数量 | `GET /api/frp/runtime` | 配置不可用时不把默认 0 显示为真实数量 |
| Docker 容器摘要 | `GET /api/docker/summary` | 仅在 available=true 时接受数量；未运行不等于故障 |
| FRP 列表与本地探测 | `GET /api/frp/tunnels` | 展示本地探测与代理运行状态；支持状态筛选与错误详情 |
| Docker 容器用量 | 现有批量 stats 接口 | 进入 Docker 页才采样；部分成功时显示 CPU / 内存各自覆盖数量 |

服务器指标响应新增 `sampledAt`、`lastAttemptAt`、`stale`。采样失败保留上一帧并标为过期；客户端区分数据获取时间与实际采样时间。旧后端未提供采样时间时显示获取时间，不编造采集时间。

## 刷新与异常

- 「我的」可见时每 5 秒读取服务器快照，每 30 秒刷新 FRP / Docker 摘要；标题支持手动刷新。
- 服务器详情可见时每 2 秒刷新资源；离开页面或进入后台停止对应轮询并取消未完成的摘要请求。
- 三个模块独立保存加载、错误、上次成功时间；请求失败保留已有数据，首次失败显示未知值。
- 退出登录清空模块状态；新服务器不会展示旧服务器的快照。
- 断连、模块错误或旧状态下禁用相关写操作；容器启停、重启及 FRP 重启沿用确认流程。
- CPU 采用整机 0–100% 口径；Docker 容器 CPU 合计使用多核口径，可超过 100%。内存按二进制单位显示。

FRP 主动停用与 Docker 暂停 / 停止使用明确的中性状态；FRP 运行、本地端口探测和公网可访问性分别理解。健康检查仅在 Docker 实际返回该信息时展示。
