# 电影港在线视频

安卓「功能」新增独立会话 **电影港 ★ 在线**，输入片名搜索，或粘贴 `66vod.com` 的影片详情页链接。结果卡片的「资源列表」提供线路与分集，可播放、复制直链及离线下载。离线下载复用已有 HLS 队列与下载设置。「资源列表」下方的「网站直达」在 App 内打开对应手机详情页，返回后继续原搜索会话。

2026-10-26 查看站点页面得到的链接结构：

- 老版 `https://www.dygangs.net` 的 `/jtrtytcdz45yfh3456.js` 会把手机用户跳转到 `https://www.66vod.com`。
- 新版搜索表单为 `POST /e/search/index.php`，使用 UTF-8 的 `keyboard`、`tempid=1`、`show=title,zhuyan`，不传老版的 `tbname=article`。
- 详情页示例：`https://www.66vod.com/dy/jqp/12959.html`（死亡幻觉）、`https://www.66vod.com/dongman/9098.html`（凡人修仙传）。
- 分集链接示例：`https://www.66vod.com/e/DownSys/play/?classid=6&id=12959&pathid2=0&bf=1`。
- 视频列表一、三使用 iframe 网页；列表二、四的播放页包含 CKPlayer 配置，`flashvars.a` 与 `video` 数组内有真实 m3u8 地址。
- 上述电影示例的列表二解析地址为 `https://s1.zoubuting.com/20210801/RKWmSjaY/index.m3u8`。站点地址及资源可用性由来源站维护。

后端 `MovieHlsService` 读取搜索及详情页，仅返回列表二、四的分集入口，按操作解析单集。`/api/chat/movie-hls/detail` 返回资源列表，`/resolve` 返回 m3u8 直链，`POST /downloads` 解析后携带播放页 Referer 加入 HLS 队列。页面抓取仅接受 `66vod.com` 的指定详情与播放路径，并处理站点返回的 gzip 内容。

此会话提供手动选择分集操作，不使用电影港磁力订阅，也不将电影港作品 ID 交给电影天堂采集接口。

「网站直达」复用原生内置浏览器。在线来源直接使用 `66vod.com` 详情页；电影港磁力来源通过 `/api/chat/movie-hls/website` 按片名匹配手机站的唯一详情页，不复用老站数字编号，无法唯一匹配时提示用户选择在线搜索结果。电影天堂卡片打开自身的对应详情页。

## 网页全屏与投屏

电影港手机网页上方提供「横屏播放」「投屏」。选择分集后，可将页面中的 m3u8 交给 Media3 原生播放器，默认横屏并保留系统栏，点击播放器右下角的切换按钮后才进入沉浸全屏；播放期间保持屏幕常亮，关闭后恢复原方向。从「资源列表」进入的电影港播放也复用同一套全屏及投屏控件。原生播放器保留网页 Referer、User-Agent 与资源 Cookie，支持从能读取进度的网页视频继续播放；播放器右上角也提供投屏入口。顶部标题栏和底部进度栏统一显隐：点击画面切换，播放中闲置 3 秒一起隐藏；全屏返回键先回到普通横屏，再返回网页。

原生播放器支持左右滑动定位，左滑后退、右滑快进，拖动时显示目标时间、总时长和变化量，并每 180 毫秒最多刷新一次播放位置以预览画面；松手后继续原先的播放 / 暂停状态，取消手势则回到原位置。底部进度条与滑动共用定位状态，位置限定在片长内，直播或无法定位的资源不启用手势。

浏览器允许影片 iframe 请求全屏，并调整电影港播放区域的宽度。视频来源优先使用本站分集解析接口；其他播放线路从网页公开播放器配置、video 元素或 m3u8 网络请求识别，不向外部网页暴露原生 JavascriptInterface。

投屏采用 SSDP 发现同一局域网的 DLNA / UPnP AVTransport 设备，通过 SetAVTransportURI、Play、Pause、Stop 控制电视，可重新搜索、切换设备、暂停 / 继续和停止。浏览页面顶部显示当前投屏设备；离开网页后投屏会话继续保存在 App 内，重新进入内置浏览器可打开控制面板。

手机与电视需要连接同一局域网，电视需开启 DLNA 且支持 HLS。该投屏方式让电视直接获取资源地址，电视能否播放还取决于其编解码能力和线路的访问限制；网页专用 Cookie / Referer 不会传给电视。
