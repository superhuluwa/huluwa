# 原生客户端接口对照

接口依据本机 huluwa 后端控制器与数据模型实现。REST 请求在配置的服务器基础地址下追加 `/api`，统一解析 `{ code, message, data }`。登录后的 REST 请求携带 `Authorization: Bearer …`。

| 功能 | 接口 |
| --- | --- |
| 初始化状态 | `GET /api/auth/status` |
| 初始化 / 登录 | `POST /api/auth/setup`、`POST /api/auth/login` |
| 修改密码 | `POST /api/auth/password` |
| 会话列表 | `GET /api/chat/sessions` |
| 历史消息 | `GET /api/chat/sessions/{id}/messages?beforeId=&limit=50` |
| 发送消息 | `POST /api/chat/sessions/{id}/messages`，正文带 `content` 和幂等 `requestId` |
| 标记已读 / 清空 | `POST …/{id}/read`、`DELETE …/{id}/messages` |
| 实时消息 | `/ws/chat?token=…`，沿用后端 WebSocket 鉴权协议 |
| HLS 下载 | `GET/POST /api/hls/downloads` |
| HLS 重试 / 取消 / 日志 | `POST …/{id}/retry`、`POST …/{id}/cancel`、`GET …/{id}/log` |
| 磁力下载列表 | `GET /api/chat/subscriptions/downloads` |
| 提交磁力 | `POST /api/chat/subscriptions/magnets/download` |
| 迅雷【Win】下载记录 | `GET/DELETE /api/xunlei-win/downloads` |
| HLS 订阅 | `GET /api/hls/subscriptions`、`POST …/quick`、`POST …/{id}/enabled`、`POST …/{id}/check`、`DELETE …/{id}` |
| 电影港订阅 | `GET /api/chat/subscriptions?includeDisabled=true`、`POST /api/chat/subscriptions`、`POST …/{id}/unsubscribe`、`POST …/{id}/check`、`DELETE …/{id}` |
| 剧集资源 | `GET /api/hls/detail`、`GET /api/chat/subscriptions/magnets/preview` |
| Frp | `/api/frp/tunnels`、`/tunnels/{name}`、`/tunnels/{name}/toggle?enabled=`、`/runtime`、`/config`、`/reload`、`/restart` |
| Docker 概览 | `/api/docker/environment`、`/summary`、`/containers?all=true`、`POST /containers/stats` |
| 容器操作 | `POST /api/docker/containers/{id}/start`、`/stop`、`/restart`；`GET …/{id}/logs`；`GET/DELETE …/{id}` |
| 镜像 | `GET /api/docker/images`、`POST /images/pull?image=&tag=`、`DELETE /images/{id}` |
| 网络 / 卷 | `/api/docker/networks`、`/api/docker/volumes` 的读取、创建及删除 |
| 服务配置 | `/api/qbittorrent/settings`、`/video/settings`、`/xunlei/settings`、`/xunlei-win/settings`、`/hls/settings`、`/chat/subscriptions/settings` |

## 适配细节

- 下载来源与订阅来源使用独立标识，避免不同来源的相同数字编号混淆。
- 后端的下载 `progress` 已是百分比，客户端不会将小于 1 的百分比误乘 100。
- `added` 作为等待任务显示，迅雷【Win】的 `success` 作为已完成显示。
- HLS 的未知进度保留为未知，不展示虚假的百分比；暂停中的 HLS 订阅不提供重试按钮。
- 某一下载或订阅来源不可用时，保留其他来源，并提示具体错误；先前已加载的该来源数据暂时保留。
- WebSocket 断开后自动重连，REST 轮询继续同步。发送失败重试复用原 `requestId`。
- 长时间断线造成历史页不重叠时，重建分页边界，允许向上补齐历史消息。
- 容器用量是容器采样的合计，不当作宿主机整体用量。没有有效采样时不编造数据。
- 新增隧道默认为服务端启用；用户选择停用创建时，创建后追加调用停用接口。
- 镜像拉取拆分仓库端口和标签，并为服务端长耗时请求保留更长的等待时间。

当前是客户端源码实现和接口静态对照，尚未通过真实服务联调。


## 在线升级

| 功能 | 接口 | 行为 |
| --- | --- | --- |
| 最新版本 | `GET /api/android/releases/latest` | Bearer 认证；`available=false` 表示暂无可用版本，否则 `release` 包含 taskId、versionName、versionCode、packageName、apkSize、sha256、signatureSha256、minSdk、publishedAt |
| 下载更新 | `GET /api/android/tasks/{taskId}/apk` | 系统下载管理器携带 Bearer 认证下载固定版本 APK，下载后校验并调起系统安装 |

“在线升级”由安卓端生成本地会话，不向聊天接口发送消息或标记已读，也不会被聊天 WebSocket 更新覆盖。
