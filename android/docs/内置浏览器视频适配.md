# 内置浏览器视频适配

电影港继续沿用现有播放解析、横屏播放与投屏能力，说明见 [电影港在线视频](电影港在线视频.md)。

`mfcn801.com` 及其子域名的 `/video/数字.html`、`/video/数字.htm` 页面复用同一套安卓播放器：

- 恢复视频原生控制面板的默认透明度与变换，避免网站固定透明度导致中央按钮无法自动隐藏；暂停时保留原生播放入口。
- 观察 Vue 异步挂载的视频元素，在实际播放后隐藏网页封面按钮，并启用内嵌播放与原生控件。
- 从当前视频组件的 `m3u8Url` 读取 HLS.js 的真实播放地址，结合 m3u8 网络请求识别资源，不把 `blob:` 地址交给原生播放器；校对组件的视频编号与当前路由，避免识别广告或上一条视频。
- 识别成功后显示「横屏播放」「投屏」，复用电影港的 Media3 播放器和 DLNA 面板；原生播放携带 Referer、User-Agent、Cookie，并从当前网页视频进度继续。
- 监听站内历史地址更新，切换视频时清理旧资源与解析任务。暂停、返回、网页全屏与关闭页面继续使用共用的媒体生命周期处理。

适配仅在安卓内置浏览器中注入，不向外部网页提供 JavascriptInterface。
