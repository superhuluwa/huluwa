# 内置浏览器视频适配

电影港播放页与 `mfcn801.com` 及其子域名的 `/video/数字.html`、`/video/数字.htm` 页面支持自动原位接管播放。电影港搜索与资源列表的说明见 [电影港在线视频](电影港在线视频.md)。

用户点击网页原来的播放区域，或网页开始实际播放后，安卓端读取真实 m3u8 和网页进度，先暂停网页媒体，再在原视频位置显示 Media3 播放器。浏览器顶部不再增加「横屏播放」「投屏」按钮栏；投屏、进度、暂停与全屏操作放在视频自身控件内，播放中闲置三秒隐藏。

- 原位播放器跟随网页滚动、缩放和布局变化，采用 TextureView 避免独立视频表面覆盖网页或浏览器标题栏。
- 原位与全屏共用同一个播放实例，切换时保留进度、缓冲和暂停状态；返回键先退出全屏，随后仍在网页原位置播放。
- 原位和全屏共用高对比度进度条：已播放部分与圆点使用亮黄色，轨道加粗至 6dp；常态圆点 20dp、拖动时 28dp，触摸区域为 48dp。紧凑原位模式在控件显示时也显示圆点，并避开全屏按钮，便于手动拖动。
- 原位和全屏的视频画面均支持左右滑动：每次右滑快进 5 秒，左滑后退 5 秒，一次手势只跳转一次，并短暂显示方向提示。跳转保留播放或暂停状态，进度限制在片长内；进度条与控制按钮保留各自操作，不可定位的直播不启用滑动跳转。
- 画面按视频比例完整显示，支持横竖屏；全屏遵循系统旋转设置，不强制横屏。资源列表的独立电影港播放器继续沿用其既有交互。
- 播放请求只在原视频区域响应；网页拖动不当作播放请求，详情页和广告区域不会额外触发电影港播放解析。
- 原生播放携带 Referer、User-Agent 和 Cookie。HLS.js 的 `blob:` 视频从当前组件的 `m3u8Url` 读取真实地址，并核对视频编号与路由；电影港优先读取公开配置或调用对应播放页解析，其他播放线路沿用 m3u8 请求识别。
- `mfcn801.com` 保留异步视频挂载适配，并恢复 WebView 原生控制面板的默认透明度，网页回退播放时也能正常隐藏控件。
- 站内跳转会清理上一条视频；进入后台暂停原生播放。原生解码失败时退回网页，本次不反复接管同一资源。

适配仅在安卓内置浏览器中注入，通过页面状态读取与原生覆盖层完成，不向外部网页提供 JavascriptInterface。
