# 灯塔功能会话

安卓「功能」列表新增「灯塔」原生会话，入口和返回继续使用现有会话导航。进入后直接展示排行榜，点击作品查看详情，详情内的追剧／追综日历入口直接弹出官方排期图片。

## 数据接入

依据用户提供的《详情页与追剧日历逆向报告.md》与 `fetch_detail.py`，并读取脚本依赖的 `fetch_webcasts.py` 及已保存的接口响应确定字段结构。安卓通过独立 OkHttp 客户端直接读取灯塔公开 H5 接口，不传送葫芦娃登录令牌，不依赖新增后端部署，不改变已归档网页端。

| 接口 | 版本 | 使用位置 |
| --- | --- | --- |
| `mtop.alipictures.gravitywave.media.rank.list` | `3.0` | 日榜、日期及剧集／综艺／动漫分类 |
| `mtop.alipictures.gravitywave.media.get` | `1.0` | 基础信息、核心播放指标、高光时刻、平台热度、走势、日历图片 |
| `mtop.alipictures.gravitywave.media.platfom.playrule.list` | `1.0` | 更新规则，仅在 `hasPlayRule=true` 时读取 |

`platfom` 是上游接口的实际拼写，不能修正为 `platform`。

使用公开 H5 的 `appKey=12574478`。首次请求建立匿名 Cookie 会话，之后按 `MD5(token + "&" + t + "&" + appKey + "&" + data)` 签名；遇到令牌过期重新建立会话并重试一次。Cookie 仅保存在客户端内存，不需要第三方账号。保留系统 TLS 证书和主机名校验，不沿用参考 Python 脚本关闭证书校验的写法。

详情固定携带 `mediaId`、`dr="[]"`、`patternName="BEACON_MEDIA_DETAIL_FILM"` 和 `patternVersion="2.0"`。按 `layers[].style.title` 与 section 内容识别模块，跳过 `dataPresent=false` 的 section，不依赖固定 section 下标。

## 页面行为

- 排行榜支持日期选择、剧集／综艺／动漫切换、播放量／市占指标切换及按平台筛选。取消会话标题栏的手动刷新按钮；今日榜单可见时约每3秒自动请求一次，持续更新时携带 `isLoop=true`。请求串行执行，进入详情、追剧日志、退出会话或应用转入后台时停止轮询；历史日期只在进入或切换条件时获取。
- 自动更新保留当前列表和滚动位置，不反复显示加载条。大盘总播放量和每部作品的播放量按前后两次同一日期快照的原始数值计算差值；在数值上方短暂显示 `+xxx`（负向修正显示负数），约2.3秒后淡出。首次加载、新增榜单项、切换类型／日期及跨日数据不计算增量，市占视图不显示播放次数增量。增量区预留固定高度，避免列表抖动。
- 详情展示最新快照，与历史榜单的选定日期分开。播放量、市占、累计播放、集均播放、平台热度和走势图全部取真实响应；缺失字段显示缺失状态，不补演示值。
- 播放与热度曲线读取 `chartDataVO.lines`。可选择曲线和日期查看数值，当日尚未结束的末段用虚线区分，平台热度不跨平台混算。
- 排行榜顶部不再显示「排行榜／追剧日志」切换栏。详情页直接显示「追剧日历」入口，点击后在当前页面弹出日历图片，不再跳转到日志页。
- 日历直接读取 `extra.releaseCalendar`，不从更新规则推算日期、集数或图片地址。`extra.bigType.value=VARIETY` 时入口显示「追综日历」。接口未提供图片时不显示入口；有图时支持原图全屏、双指缩放、拖动和重置缩放。
- 更新规则加载失败只影响规则卡片，已获取的详情和日历仍可查看。榜单、详情刷新失败时保留上次内存快照并标明状态。
- 收藏、观看集数和最多160字的观剧感受按当前葫芦娃服务器及账号存入本机 SharedPreferences。记录时间使用设备当前时间；取消追剧保留历史日志。日志不会上传到灯塔，也不自动同步到其他设备。

## 代码位置

| 文件 | 职责 |
| --- | --- |
| `data/DengtaRepository.kt` | MTOP 请求、Cookie、签名、令牌刷新与取消请求 |
| `data/DengtaModels.kt` | 榜单、配置化详情、指标单位、走势图与个人记录模型 |
| `data/DengtaJournalStore.kt` | 按服务器与账号隔离的本机持久化 |
| `DengtaViewModel.kt` | 页面状态、请求切换、快照、追剧与记录操作 |
| `ui/DengtaScreen.kt` | 会话框架、排行榜、筛选、日期选择与公共组件 |
| `ui/DengtaDetailScreen.kt` | 详情、核心指标、平台热度和真实走势 |
| `ui/DengtaJournalScreen.kt` | 追剧列表、个人日志、日历预览与图片缩放 |

现有 `Models.kt`、`HuluwaViewModel.kt`、`HuluwaRoot.kt` 和 `Components.kt` 仅增加灯塔会话的分类、导航、摘要和图标接入。
