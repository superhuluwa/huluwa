# 番茄书源接口

参考开源阅读（Legado）的书源模型，在现有番茄小说搜索、目录、正文和章节缓存之上，
新增一层统一的书源接口，并支持整本 TXT 导出和开源阅读书源 JSON 生成。

现有安卓链路 `/api/fanqie/**` 保持不变，书源接口是并列新增，不影响归档网页端。

## 一、结构

| 组件 | 作用 |
|---|---|
| `service/source/BookSource` | 书源契约：搜索 / 详情 / 目录 / 正文 |
| `service/source/FanqieBookSource` | 番茄实现，复用现有搜索会话和章节缓存 |
| `service/source/BookSourceRegistry` | 按 ID 注册和查找书源 |
| `service/source/BookExportService` | 异步整本 TXT 导出，优先复用缓存，缺失章节按批补齐 |
| `security/BookSourceTokenService` | 长期只读书源令牌（365 天，可整体吊销） |
| `security/BookSourceAuthInterceptor` | 只对 `/api/sources/**` 生效的书源鉴权 |
| `web/BookSourceController` | 书源接口 |
| `web/BookSourceTokenController` | 令牌签发、吊销、Legado 书源 JSON 生成 |

## 二、鉴权

- `/api/sources/**`：只接受书源令牌（`Authorization: Bearer <token>`，也兼容 `?token=`）。
- `/api/source-tokens/**`：走登录令牌，用于管理书源令牌。
- `/api/fanqie/**`：仍走登录令牌。

书源令牌与登录令牌使用独立密钥和独立版本号，改密码或吊销登录令牌不会影响书源。

## 三、书源接口

```
GET  /api/sources                                   书源列表
GET  /api/sources/{sourceId}/search?key=&page=&size=  搜索
GET  /api/sources/{sourceId}/books/{bookId}         详情
GET  /api/sources/{sourceId}/books/{bookId}/chapters 目录
GET  /api/sources/{sourceId}/books/{bookId}/chapters/{chapterId} 正文
POST /api/sources/{sourceId}/books/{bookId}/export  开始导出 TXT
GET  /api/sources/exports/{taskId}                  导出进度
GET  /api/sources/exports/{taskId}/download         下载 TXT
```

搜索分页支持两种方式：

- `page`：从 1 开始，对应开源阅读的 `{{page}}`。
- `cursor`：优先使用；接口返回 `nextCursor`，为 `null` 表示没有更多。

目录接口每条章节额外返回相对路径 `url`（`books/{bookId}/chapters/{chapterId}`），
供只能按 JSONPath 取值的阅读器直接请求正文。

目录和正文请求在书籍尚未进书架时会自动调用 `open` 完成目录缓存，
因此外部阅读器不需要先走 App 的「加入书架」。

## 四、TXT 导出

- 任务在 `book-export` 单线程后台执行，接口立即返回任务状态。
- 先复用 `data/fanqie/<书号>/<章节>.txt` 缓存，缺失章节按每批 8 章补齐并写回缓存；
  中途失败后重新导出只补缺章。
- 文件写入 `data/exports/<书名>-<时间戳>.txt`，先写临时文件再原子改名。
- 单批失败不终止整本导出，导出文件里该章标记为「本章未能下载，可重新导出补齐」。
- 任务记录上限 64 个，已结束任务保留 1 天。

安卓端和网页端可用登录鉴权下的 `/api/fanqie/books/{bookId}/export` 与
`/api/fanqie/exports/{taskId}/download`，不需要书源令牌。

## 五、开源阅读导入

```
GET /api/source-tokens/fanqie/legado?baseUrl=https://你的葫芦娃地址
```

返回 `token` 和可直接保存为 `.json` 导入的书源配置。注意事项：

- `baseUrl` 留空时按 `X-Forwarded-Proto` / `X-Forwarded-Host` / `Host` 推断。
- 令牌内嵌在书源的 `header` 里，这份 JSON 等同于凭证，不要公开分享。
- 书源 JSON 的规则字段需要按实际使用的阅读版本实测一次，尤其是
  `ruleSearch` / `ruleToc` / `ruleContent` 的 JSONPath 写法。
- 令牌可通过 `POST /api/source-tokens/revoke` 整体吊销。

## 六、已知限制

- 番茄为单设备会话，搜索、阅读、导出共用上游配额；导出使用独立客户端但同样受配额限制。
- 交互阅读与书源接口共享 `FanqieLibraryService` 的远程请求锁，高并发时会快速返回 503。
- 上游接口和签名可能随 App 版本变化，失败时需对照 `fanqie/fanqie_api.py` 复查算法。
