# 懂片帝接入说明

懂片帝（`dongpian19.com`，备用域名 `dongpian.ai`）是「按片名搜索 → 多播放源」的影视聚合站，
形态与电影天堂接近：搜索返回作品卡片，每部作品下有多条播放线路，每条线路是各集的视频直链，可能是 m3u8、MP4 或无扩展名的视频地址。

本站没有公开 API 文档，接口是从其 Web 前端包里还原出来的。

## 接口清单

下列四个接口都要求 HMAC-SHA256 签名。

| 用途 | 方法与路径 | 关键返回 |
| --- | --- | --- |
| 搜索 | `GET /v1/browse/catalog?q=片名&limit=20` | `cards[]`：作品卡片 |
| 详情 | `GET /v1/catalog/{作品ID}` | 海报 / 年份 / 地区 / 类型 + `episodes[]`（每集带 `token`） |
| 播放解析 | `GET /v1/playback/resolve/{该集token}` | `line_options[]`：该集全部线路 |
| 官方线路兑换 | `POST /v1/playback/resolve-line` | 请求体 `{ticket, episode_token}`；成功返回 HTTP 201 与 `line` |

另有 `/v1/playback/episodes/{token}` 返回分集 + 线路的组合，本项目没有用到。

## 请求签名

签名算法在前端包 `assets/movie-card-runtime-*.js` 的 `Ta()` 函数里，
密钥 `Jo` 硬编码在同文件的 `Aa()` 附近。

```
signature = HMAC-SHA256(secret, METHOD + "\n" + pathAndQuery + "\n" + timestamp + "\n" + nonce)
```

- `METHOD`：实际请求方法（`GET` 或 `POST`）
- `pathAndQuery`：`/v1/...` 开头，含查询串，必须与实际请求逐字一致
- `timestamp`：毫秒时间戳（`Date.now()`）
- `nonce`：16 字节随机数的小写十六进制（32 个字符）
- 输出：小写十六进制

三个头都要带上：`x-ai-movie-timestamp`、`x-ai-movie-nonce`、`x-ai-movie-signature`。

未签名时站点返回 `401 {"code":"invalid_request_signature"}`。

## 线路的两类形态

`line_options[]` 里每条线路有 `url` 与 `resolved`：

1. **可直接播放**（`resolved: true`，`url` 是 `http(s)://…m3u8`）：第三方资源站直链，
   可播放、复制和离线下载。
2. **需兑换**（`resolve_required: true`，`url` 是 `resolve://av_…` 票据）：站点官方线路，
   调用兑换接口时去掉 `resolve://` 前缀，并传入该集自己的 `episode_token`。
   点选线路时只兑换第一集，其余集保留空地址，在用户点击「解析」时兑换。
   可否兑换受站点当前的登录、等级、额度及频率规则约束。

官方兑换结果按 `line.resolved=true` 与绝对 HTTP(S) 地址识别，不能要求 URL 含 `.m3u8`。
2026-10-27 排查《狂飙》第 1 集时，官方 Z 返回 `url_kind=mp4`，地址却以 `.jpg~…image.image` 结尾，
媒体内容的文件头为 MP4 的 `ftypisom`；官方 B 返回无扩展名直链，爱奇艺返回 m3u8，三条兑换均为 HTTP 201。
原先的 m3u8 后缀校验会丢掉前两条成功结果，继而误报「兑换配额已用完」。

安卓端对这些视频直链提供播放和复制；现有离线队列只接收 m3u8，因此其他格式不显示离线下载按钮。
未解析剧集必须保留在列表中，不能因为 `url` 为空而过滤掉，否则官方线路只能看到第一集。

## 为什么线路要懒解析

每条线路的**每一集**都要单独请求一次 `/v1/playback/resolve`（单次约 2–3 秒）。
一部 36 集的剧，只解析 1 条线路要 10 秒左右，全量 23 条线路就是几分钟。

所以：

- `/api/dpd/detail` 只探测第一集，用来拿到**线路名清单**（`dpdLines[].episodes` 为空）；
- 直链线路：`/api/dpd/line` 以 6 并发解析前 12 集，其余后台补齐；
- 官方线路：`/api/dpd/line` 只兑换第一集，其余集通过 `/api/dpd/episode` 按需兑换；
- 返回分集清单时包含尚未解析的条目，地址留空，安卓端显示「解析」按钮；
- 第三方直链缓存到 `Episode.lines` 并落库 6 小时；官方票据和已兑换地址只缓存在内存中，
  作品详情缓存 30 分钟，同一部剧来回切线路可复用已有结果。

## 维护提示

- **签名密钥轮换**：站点改版后可能出现大量 `401 / 签名校验失败`。此时重新拉取前端包，
  找到 `movie-card-runtime-*.js` 里的 `Ta()` 与 `Jo`，更新 `DongPianSearchService.SECRET`。
- **域名更换**：改 `DongPianSearchService.BASE_URL` 即可，备用域名 `dongpian.ai` 接口与签名一致。
- **不参与订阅追更**：站点按集下发 `token`，没有稳定的分集地址可比对更新，
  因此懂片帝卡片没有「订阅」按钮，也不进「我的订阅」。

## 与电影港 / 电影天堂的隔离

懂片帝是**独立一套**，不复用另外两个来源的卡片、弹层与载荷结构：

| 层面 | 电影港 / 电影天堂 | 懂片帝 |
| --- | --- | --- |
| 载荷类型 | `playSources` / `magnets` | `kind=dpd-title` / `dpd-detail` / `dpd-line` |
| 标识字段 | `id` / `url` | `dpdId` / `pageUrl` |
| 安卓卡片模型 | `FilmCard` | `DpdCard`（`ChatMessage.dpd`） |
| 安卓弹层 | `AppSheet.Films` | `AppSheet.Dpd` |
| 接口 | `/api/hls/**`、`/api/chat/**` | `/api/dpd/**` |
| 订阅追更 | 支持 | 不支持（站点按集下发 token，无稳定地址可比对） |

懂片帝载荷故意不带 `url`，因此不会被 `ChatMessage.film` 误判成 `FilmCard`。
